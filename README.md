**Product Owner and developer** · Roubaix, France · Open to freelance projects and roles

I take software products from the first conversation to production, and I stay after launch. I scope the need with the people who will use the tool, turn it into a backlog, design the interface, build it, deploy it and keep it running. One person accountable from end to end, so nothing gets lost between product, design and engineering.

---

### Philosophy

- **Software should give power back to its users.** People and small companies should own their tools and their data: local-first when possible, no lock-in, no account they did not ask for.
- **Start from the work, not from the tech.** I first look at how the team works today, with which spreadsheets and which software, and where it loses time. The stack comes after.
- **Ship early, then iterate with real users.** A small version in production teaches more than a long specification.
- **Build on what already works.** When existing software stays the source of truth (Sellsy, WordPress), I connect to it instead of replacing it.
- **Keep it simple to run.** Fewer moving parts, clear documentation, deployments the client can understand.

### How I run a project

| Phase | What I take care of |
| --- | --- |
| **Discovery** | Interviews and workshops with the team, current process, pain points, success criteria |
| **Product** | Scope, user stories, prioritized backlog, roadmap, trade-offs between value and effort |
| **Design** | User flows, mockups, design systems, accessibility |
| **Build** | Full-stack web apps, native macOS and iOS apps, integrations, automated tests |
| **Ship** | Deployment on Vercel or self-hosted servers with Docker, signed and notarized apps, data migration |
| **Run** | Training, support, monitoring, iterations based on feedback |
